# How to run this project
Download Utopia-main from this project page
Extract all from the zipped file

Go to this link: https://processing.org/download
This will take you to Processing's official download page. Download the most recent version.

Once you have finished downloading Processing, open it and then click on "File" -> "Open..."
It will prompt you to select a Processing sketch (or a PDE file).
Click on the unzipped file (or Utopia-main) and then click on Utopia.pde

Once you have opened the project file, click "Run" and you should be running the project!
